# AWS System Monitor Dashboard

A web-based system monitoring dashboard deployed on AWS EC2. The dashboard displays real-time system information such as CPU usage, memory usage, disk usage, and server uptime.

## 📌 Problem Statement

Build and deploy a web-based system monitoring dashboard on AWS EC2 that allows users to monitor important server resources through a simple web interface.

## 🚀 Features

- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- Server uptime monitoring
- Automatic dashboard refresh
- Web-based monitoring interface

## 🛠️ Technologies Used

- AWS EC2
- Amazon Linux 2023
- Python
- Flask
- Psutil
- HTML
- CSS
- JavaScript
